# Gnomish Factory 0.1.0

The first release: the factory ships as a distribution archive. Install it with
Java 25 or newer and git on the machine:

1. Download `gnomish-0.1.0.tar.gz` (or `.zip`) and `SHA256SUMS` from this page.
2. Check the archive: `sha256sum -c --ignore-missing SHA256SUMS`; optionally
   `gh attestation verify gnomish-0.1.0.tar.gz --repo oinsio/gnomish-factory`.
3. Unpack it and put `gnomish-0.1.0/bin` on `PATH`.
4. `gnomish --version` prints `0.1.0`.

`bin/gnomish` checks for Java 25 or newer and passes every argument to the
factory unchanged; extra JVM options go in `GNOMISH_JAVA_OPTS`. The SBOM of the
factory jar is published beside the archives as `gnomish-0.1.0-cyclonedx.json`.

## Upgrading from a build of the repository

If you ran the factory from a jar built out of the repository, everything it
kept now lives under the factory home (`~/.gnomish`, or `GNOMISH_HOME`), per
project. Nothing is migrated automatically. Before the first command of this
release, in this order:

1. **Finish or discard aborted tasks** with the build you have now: their
   worktrees live in the old folders that the next step deletes.
2. **Delete the old folders**: `rm -rf ~/.gnomish/logs ~/.gnomish/serve
   ~/.gnomish/worktrees`. At the next start, `git worktree prune` drops the
   clones' records of the deleted worktrees.
3. **Register every clone**: `gnomish project add <name> --dir=<path>`, once per
   clone. A command run in an unregistered directory stops and prints the line
   to paste.
4. **Move the secrets** out of environment variables into files: one file per
   secret, named exactly like the variable, mode `600`, in
   `~/.gnomish/projects/<name>/secrets/` (one project) or `~/.gnomish/secrets/`
   (every project). Environment variables are still read last.
5. **Move launcher options into the project file.** `--factory.*` options a
   wrapper script passed on every call belong in
   `~/.gnomish/projects/<name>/project.yaml`; `gnomish project show <name>` shows
   every setting with its origin. Delete the wrapper: `bin/gnomish` injects no
   options.
6. **Rename the default binding key.** `factory.bindings.default-binding`, the
   undocumented spelling that bound by accident, binds nothing any more; write
   `factory.bindings.default` (for example `factory.bindings.default: host`).

The operator guide's "Setting up a project" section describes the layout in
full.
